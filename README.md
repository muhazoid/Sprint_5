## **Тестирование приложения Stellar Burgers**

Данный проект содержит набор автоматизированных тестов для проверки функциональности учебного сервиса Stellar Burgers — приложения для заказа бургеров из необычных ингредиентов. Тесты охватывают регистрацию пользователей, вход в аккаунт, работу с личным кабинетом и конструктором бургеров.

---

## **Структура проекта**

- **conftest.py** — файл с фикстурами (создание драйвера браузера для каждого теста).
- **helpers.py** — вспомогательные функции (генератор уникальных email, тестовые данные).
- **locators.py** — файл с локаторами всех элементов на страницах приложения.
- **tests/** — директория с тестами:
  - **test_constructor.py** — тесты конструктора бургеров.
  - **test_login_page.py** — тесты входа в аккаунт.
  - **test_profile_page.py** — тесты личного кабинета.
  - **test_registration_page.py** — тесты регистрации.




---

## **Используемые фикстуры (conftest.py)**

Для изоляции тестов и управления браузером используется фикстура:

***driver***
Создает экземпляр браузера Chrome перед каждым тестом и закрывает его после завершения.

---

## **Вспомогательные функции (helpers.py)**

***generate_unique_email()***
Генерирует уникальный email для регистрации в формате: `имя_фамилия_когорта_3цифры@домен`.


***TestData***
Класс с фиксированными тестовыми данными:
- `LOGIN_EMAIL` — email для входа.
- `LOGIN_PASSWORD` — пароль для входа.
- `USER_NAME` — имя пользователя.

---

## **Локаторы (locators.py)**

Все локаторы элементов на страницах вынесены в отдельный файл и сгруппированы по классам:

- **Urls** — URL-адреса страниц приложения.
- **RegisterPageLocators** — элементы страницы регистрации.
- **MainPageLocators** — элементы главной страницы и конструктора.
- **LoginPage** — элементы страницы входа.
- **RecoverPageLocators** — элементы страницы восстановления пароля.
- **ProfilePageLocators** — элементы страницы профиля.
